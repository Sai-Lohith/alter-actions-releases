# Alter Actions: downloads

Select text in any Windows app, press Alt + A, and pick an action (summarize, explain, rephrase, fix grammar…).

**Install:** open the latest release and download `AlterActions-win-Setup.exe`.
Windows may show a blue "protected your PC" screen: click More info → Run anyway.
The app updates itself after that.

Found a bug? Tell Lohith. Include what you selected, what you pressed, and the log at `%LOCALAPPDATA%\AlterActions\logs\alteractions.log`.
